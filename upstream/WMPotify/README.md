# WMPotify source reference

This folder contains selected, unmodified SCSS source files from [Ingan121/WMPotify](https://github.com/Ingan121/WMPotify), a Windows Media Player 11 inspired Spicetify theme. It gives Aerify a concrete reference for compact navigation, player controls, Home cards, and sidebar layout while Aerify keeps its own implementation.

- Upstream branch: `master`
- Pinned source commit: [`6aa2b5f0b40fdfc596590a6f4c473cffac65ee4a`](https://github.com/Ingan121/WMPotify/commit/6aa2b5f0b40fdfc596590a6f4c473cffac65ee4a) (2026-09-10)
- Upstream manifest: no release version number; the upstream README lists Spotify 1.2.45–1.2.99 support at this revision.
- License: `license.txt` (MIT), subject to the exclusions in `.licignore`. In particular, `theme/src/resources` and `theme/dist` are excluded and are not copied here.

The files retain their original paths beneath `theme/src/`. They are reference source, not an Aerify build dependency. No upstream JavaScript, generated CSS, or image resources are included.
